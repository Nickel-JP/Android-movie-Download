# UI設計

参照：ユーザー指定の共有リンクの転送先 [Android Niceties](https://androidniceties.tumblr.com/)。掲載されているGoogle Fitなどの画面から、余白、文字の強弱、主操作の配置、Androidの操作慣習を参考にしました。

## 保存画面

- URL入力 → 保存形式 → 品質設定の順に操作できます。
- 「貼り付け」とURL消去を明示し、共有メニューからの追加にも対応します。
- 開始ボタンを下部に固定し、キーボード表示中にも操作できます。
- 動画・MP3・WAVで必要な設定だけを表示します。
- 品質は設定項目をタップして選択します。

## リスト選択画面

- プレイリスト・ミックスを50件ずつ一覧化し、各行の左にチェックボックスを置きます。
- 初期状態は未選択。「全選択」「全解除」でまとめて操作できます。
- 全選択は続きも取得して最大1000件まで選択します。
- 選択件数と保存形式を明示し、選択した項目だけを保存します。
- 一覧は遅延表示し、長いリストでもスクロールできます。

## 履歴・設定

- 履歴は「すべて」「進行中」「完了」で絞り込めます。
- 進捗、処理状態、キャンセル、再試行、保存したファイルを開く操作をまとめます。
- アプリの更新と動画取得エンジンの更新を設定画面上部に配置します。
- ライト・ダーク・端末に合わせる表示を選択でき、設定を保持します。
- 更新配信先の変更は詳細設定に置いています。

## 検証

- 小型画面、文字倍率1.6、明暗テーマ、キーボード表示時の開始ボタンをテスト。
- Android 15のエミュレーターで実際の表示を確認。

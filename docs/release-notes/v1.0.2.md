# Android movie Download 1.0.2

## プレイリスト・ミックスの選択保存

- リストURLを確認すると、含まれる動画を一覧表示します。
- 各項目の左側のチェックボックスで個別選択・個別解除できます。
- 「全選択」「全解除」と選択件数を表示します。
- 全選択時はリストの続きも取得し、取得できた保存可能な項目をまとめて選択します。
- 選択した動画だけを指定の画質・音声形式で保存キューへ登録します。
- 動画ごとに進捗、キャンセル、再試行を利用できます。

## 互換性と制限

- リストは50件ずつ取得し、一覧と待機中のキューは最大1000件です。
- ミックスの内容は取得時点のものです。サイト側で内容が変動する場合があります。
- ライブ配信中やURLを取得できない項目は選択できません。
- 1.0.1からアプリ内の「設定」→「アップデートを確認」で更新できます。
- Android 10以降のarm64端末向け。同じ署名で設定と履歴を引き継ぎます。

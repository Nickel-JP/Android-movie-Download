# Android movie Download 1.0.6

## 保存時のエラーを修正

- Android 15以降で変換・保存中に発生する「Starting FGS with type none」エラーを修正しました。
- バックグラウンドの進捗通知更新と、連続した保存処理の終了動作を改善しました。
- 次の動画の追加やキャンセルと処理開始が重なったときの競合を修正しました。
- 保存前の画質確認を、映像のフレーム変換に依存しない方法へ変更しました。縦動画の短辺とfps上限の判定は維持しています。
- 履歴の「エラー詳細」から、省略されていた末尾まで確認・コピーできるようになりました。

## 更新と互換性

- 「設定」→「アップデートを確認」から更新できます。
- 更新後、失敗した履歴の「再試行」から保存し直してください。
- 同じ署名で設定と履歴を引き継ぎます。Android 10以降のarm64端末向けです。

## 検証

- Flutterの静的解析と28件のテスト、Kotlin JVMテスト22件、Android 15の端末テスト17件に成功。
- 実際のバックグラウンドサービスで動画とMP3を連続保存し、完了後に通知が消えることを確認。
- 合成した縦・横動画、分数fps、画質上限、音声のみ、カバー画像、破損ファイルの検査を確認。
- 小型画面・大きい文字でエラー全文の閲覧とコピー・閉じる操作を確認。
- A301SH実機と報告された動画そのものの再現は未検証です。取得元や動画に固有のエラーが続く場合は「エラー詳細」で内容を確認できます。

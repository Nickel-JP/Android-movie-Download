# Android movie Download 1.0.5

## 詳細設定のGitHub URL

- 詳細設定の更新配信先を、GitHubのURLで表示します。
- URLの文字列を選択してコピーできます。
- 更新配信先の変更画面も、GitHubのURLで表示・入力できます。

## 更新と互換性

- 「設定」→「アップデートを確認」から更新できます。
- 同じ署名で上書き更新し、設定と履歴を引き継ぎます。
- Android 10以降のarm64端末向けです。

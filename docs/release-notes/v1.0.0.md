# Android movie Download 1.0.0

## 新機能

- YouTube・ニコニコ動画のURLを入力・共有して保存できます。
- 配信品質の範囲内で最大4K／60fpsの動画を選択できます。
- MP3は最大320kbps、WAVは非圧縮PCMで保存できます。
- 進捗通知、キャンセル、再試行、履歴を利用できます。
- URL入力と品質設定を順に操作でき、開始ボタンは画面下に固定しています。
- ライト・ダーク表示と、履歴の絞り込みに対応しています。
- アプリ内からyt-dlpを更新できます。
- 同梱のyt-dlpは2026.08.19です。
- GitHub Releasesからアプリ本体の更新を確認し、Androidのインストール確認画面へ進めます。

## 互換性

- Android 10以降のarm64端末向けです。
- A301SH・Android 15を対象に開発しています。A301SH実機での動作は未検証です。
- 元動画より高い画質・fps・音質にはなりません。
- 再生可否は端末とプレーヤーの対応コーデックに依存します。
- 16KB配置への対応は静的検証済みです。16KB環境での実行は未検証です。

## 検証

- Flutterの静的解析、URL・更新情報・更新ファイル・画面操作のテストを実施。
- Androidの画質上限・fps上限のテストとLintを実施。
- キャンセル時の終了処理を修正し、Android 15で保存と子プロセスの終了を検証。
- Android 15のFFmpegでMP3 320kbpsとWAV（48kHz・24bit）の変換を確認。
- Androidのインストール確認画面からの上書き更新とデータ保持を確認。
- Android 15のエミュレーターで起動、画面表示、yt-dlpのアプリ内更新を確認。
- YouTube・ニコニコ動画からの実際の取得は未検証です。
- 個別の変換結果と未検証事項はリポジトリの`docs/VALIDATION.md`に記載します。

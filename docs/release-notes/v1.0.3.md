# Android movie Download 1.0.3

## 更新画面を見やすく

- 更新内容を**見出し・箇条書き・強調**として表示します。
- 更新前後のバージョンを分かりやすく表示します。
- 長い更新内容をスクロールしても、容量と「あとで」「更新する」は下部に表示されます。
- ライト・ダーク表示、小型画面、横向き、大きな文字に対応します。

## 更新と互換性

- アプリの「設定」→「アップデートを確認」から更新できます。
- 旧版に表示する更新案内も、Markdownの記号を除いた読みやすい本文に変更しました。
- 新しい更新画面のレイアウトは、このバージョンをインストールした後の更新確認から適用されます。
- 同じ署名で上書き更新するため、設定と履歴を引き継ぎます。
- Android 10以降のarm64端末向けです。

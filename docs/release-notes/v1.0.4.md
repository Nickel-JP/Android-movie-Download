# Android movie Download 1.0.4

## 共有からダウンロード

- 動画アプリやブラウザーの共有先で **Android movie Download** を選ぶと、URLを保存画面へ入力します。
- 「ダウンロードしますか？」と、現在の保存形式・画質を表示します。
- 確認後に取得を開始します。キャンセルしてもURLは残り、保存形式や画質を変更できます。
- 起動時・起動中の共有と、同じURLをもう一度共有する操作に対応します。
- リストを共有した場合は、確認後に保存したい動画を選択できます。

## YouTube Shorts

- ShortsのURLと共有用のクエリを保持して動画を保存できます。
- 縦動画も指定した画質・fpsの上限内で保存します。
- サイト側の配信品質・認証・アクセス制限は取得可否に影響します。

## 更新と互換性

- 「設定」→「アップデートを確認」から更新できます。
- 同じ署名で上書き更新し、設定と履歴を引き継ぎます。
- Android 10以降のarm64端末向けです。
- 共有メニューの表示順は送信元アプリやAndroid側に従います。

# Android movie Download 1.0.1

## 対応範囲の拡張

- YouTube・ニコニコ動画に限定していたURL受付を、yt-dlp対応サイト全般へ拡張しました。
- HTTP／HTTPSのスキーム、ポート、クエリ、フラグメントを保持して解析します。
- 各サイトのCookieファイルを取り込めます。
- 直接の動画・音声リンクと、画質・コーデック情報を返さない配信形式にも対応しました。
- 画質情報が不明な動画は、保存前に実際の映像を検査して指定した画質・fpsの上限を確認します。
- 保存画面の表示を対応範囲に合わせて更新しました。

## 更新と互換性

- 1.0.0からアプリ内の「設定」→「アップデートを確認」で更新できます。
- 同じ署名・パッケージ名で上書きするため、設定と履歴を引き継げます。
- Android 10以降のarm64端末向けです。
- 取得可否はyt-dlpの対応状況とサイト側の認証・アクセス制限にも依存します。
- 現在配信中のライブ、プレイリストの一括処理、HTTP／HTTPS以外のスキームは対象外です。

## 検証

- Flutterの静的解析と10件のテストに成功。
- Kotlin JVMテスト8件と、Android 15の端末テスト5件に成功。
